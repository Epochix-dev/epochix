# Code of Conduct

Epochix follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, criticise work rather than people,
and keep issues and discussions about the project.

This applies in every project space — issues, pull requests, discussions and
reviews — and to anyone representing the project elsewhere.

## Reporting

If someone's behaviour makes the project an unwelcome place, tell the
maintainer privately: open a
[private security advisory](https://github.com/Epochix-dev/epochix/security/advisories/new)
(it is private to you and the maintainer, and not limited to security issues),
or contact [@kv4u](https://github.com/kv4u) on GitHub. Reports are read
promptly and kept confidential. The consequences follow the Covenant's
enforcement guidelines, from a private note up to a ban from project spaces.
